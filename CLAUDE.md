# halyavka.net — ГДЗ-сайт (Astro, статика)

- Запуск: `pnpm dev --port 4399` (см. `.claude/launch.json`). Билд: `pnpm build`.
- Стек: Astro + Tailwind (`darkMode: 'class'`), View Transitions (`astro:page-load` в скриптах компонентов).
- Бренд: червоний `#C1121F`, темно-синій `#003049`, кремовий `#FDF0D5`; тёмная тема через `:global(.dark)`.
- Классическое ГДЗ: ответы = webp-картинки в `public/images/<klas>/<book>/`, данные книги в `src/data/<author>-<subject>-<klas>.ts`, страница в `src/pages/<klas>-klas/gdz-.../index.astro`, просмотрщик — `ExerciseGallery.astro`.
  Структуру (§, розділи, состав вправ) для новых книг брать из HTML-файла `зміст`, который
  пользователь кладёт в папку книги, — это точные данные, навигатор от NotebookLM для них НЕ нужен.
  Парсеры-генераторы data-файлов: `scripts/gdz/` (там же README и что делать, когда доедут
  недостающие блоки). Обязательная проверка перед сдачей — плоский список кнопок против реальных
  файлов в `public`: 0 missing / 0 extra / 0 dup. Имена файлов приводить к схеме СТАРОЙ страницы,
  иначе ломаются внешние deep-link-и `/…/#123`. Трекер всей пакетной работы — `PERENOS-STATUS.md`.

## Хімія 8 клас, Григорович — книга на двух площадках

03.09.2026 интерактивное ГДЗ по химии **уехало на поддомен**
`~/Developer/himiya.halyavka.net` (сайт himiya.halyavka.net). Причина: одна страница
весила 4,3 МБ и 41 тыс. тегов — больше, чем весь остальной текст сайта вместе взятый.
Здесь осталась обычная книга в общем формате сайта: `ExerciseGallery` + картинки.

- Страница: `src/pages/8-klas/gdz-himiya-grygorovych/index.astro` — **125 КБ, 1 104 тега**
  (для сравнения: geometry-ister — 184 КБ). Данные: `src/data/grygorovych-himiya-8-images.ts`.
- Картинки: `public/images/8-klas/gdz-himiya-grygorovych/` — 403 webp, 26 МБ, в среднем 65 КБ.
  Это НЕ сканы: они нарисованы из наших же текстовых ответов режима «Списати».
  Имя файла = id задания (`1.webp`, `pom-11.webp`, `nd2-dosl-1.webp`).
- **И картинки, и data-файл генерируются НЕ ЗДЕСЬ**, а в репозитории поддомена, где лежат
  исходные тексты решений:

  ```bash
  cd ../himiya.halyavka.net
  pnpm render                                                    # картинки сюда, в public
  pnpm gen-images-data > ../halyavka-CLODE/src/data/grygorovych-himiya-8-images.ts
  ```

  Руками эти два файла не править — перезатрёт. После генерации обязательна сверка
  плоского списка кнопок с файлами: 0 missing / 0 extra / 0 dup (сейчас сходится, 403/403).
- `src/data/grygorovych-himiya-8.ts` (3,1 МБ текстов решений), `SolutionGallery.astro`
  и `ChemTrainer.astro` здесь больше не нужны — они переехали. Пока лежат на месте,
  чтобы ничего не сломать на переходный период; удалять — отдельной задачей, после того
  как поддомен встанет на боевой домен.
- `/8-klas/gdz-himiya-grygorovych/rozdil-2/` — страница-заглушка: canonical + JS-редирект
  на поддомен, хеш переносится (`#160` доедет). Честный 301 лучше дописать в `.htaccess`
  на сервере — его в репозитории нет, он в protect-списке `deploy.sh`.

### Мостик между площадками

У `ExerciseGallery` появился опциональный проп **`deepLinkBase`**: если он задан, под
просмотрщиком появляется ссылка «🧠 Покроковий розбір цього завдання», и её href
пересобирается при каждом переключении номера. Для остальных книг проп не задан —
ничего не меняется. Обратный мостик (с поддомена сюда) — в `BookHero` поддомена, поле
`mirror` в его `src/data/books.ts`.

### Рендерер картинок из текста

`scripts/gdz/render-answers.ts` и `scripts/gdz/gen-images-data.ts` — копии тех, что
работают на поддомене (там они и живут «по-настоящему», рядом с данными). Приём общий
и переиспользуемый: **если у книги есть текстовые ответы, картинки к ней можно нарисовать,
а не сканировать.** SVG → sharp, без браузера. Строки в `answer` уже разбиты по 72 символа,
поэтому перенос слов не нужен; пустая строка массива = половинный отступ на картинке.
