# Разбор писем «Помилка: вправа N»

Письма приходят в Gmail ztrmnn@ (в Chrome это `mail.google.com/mail/u/1/`), поиск `помилка вправа`.
Учебники — `/Volumes/UNTITLED/учебники/<клас>/`; это сканы без текстового слоя, поэтому:

    python3 scripts/gdz/oshibki/ocr_book.py "<pdf>::<метка>"   # OCR в ~/.cache/halyavka-ocr/<метка>/pNNN.txt
    grep -n "^482" ~/.cache/halyavka-ocr/<метка>/*.txt          # страница с вправой

ВНИМАНИЕ: издания на диске часто новее, чем на сайте (Будна, Заїка, Пономарьова) —
номера сдвинуты, сверять по тексту условия, а не по номеру.

Правка картинок старого формата (Times / Verdana на белом): `patch_lines.py` —
`lines()` находит строки, `fit_size()` подбирает кегль по нетронутой строке,
`redraw_line()` перерисовывает строку. Если шрифта нет в системе (Calibri) —
склеивать слово из букв той же картинки. Картинки нового формата (УМОВА / У ЗОШИТ) —
писать HTML и снимать `save my images/_НЕ УДАЛЯТЬ/Мой рендер/render-work/bin/exercises-mob --css user6.css`.

Оригинал перед заменой — рядом как `N.webp~` (в зеркало воркера `*~` не попадает).
Выкладка: `bash scripts/workers.sh images --go`.
